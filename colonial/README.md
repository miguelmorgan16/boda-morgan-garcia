# Portal de cotizaciones Colonial

Sitio estático para que los clientes de Colonial elijan productos y servicios y envíen una solicitud de cotización.

- `index.html`: la página (español e inglés).
- `catalog.js`: el catálogo, generado desde QuickBooks. Cada fila: id, categoría, precio "desde", unidad, nombre/descripción ES y EN.
- `assets/`: logo y favicon, con los colores oficiales del libro de marca.
- Las solicitudes llegan por Formspree (formulario `mbgozrgl`).
